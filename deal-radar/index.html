Deal Radar

When a startup raises money, it files a short form with the SEC. Every weekday, Deal Radar reads the new filings, skips the companies you've already seen, and tells you which new ones match what an investor is looking for, often before the funding news is public.

Try it live View the code

What it does

  • Reads every new filing. The form is called a Form D. Deal Radar drops investment funds and repeat filings, then looks up what each remaining company actually does.
  • Gives each company one of four answers: fits, maybe, unknown or no fit, with a short reason.
  • Remembers. You never see the same company twice, and your own notes stay with it.
  • Anyone can try it. Visitors can write their own criteria and see which companies match, or ask for a chart.

How it's built

  • It doesn't guess. If a lookup fails or the AI gives a broken answer, that's logged as an error and tried again later. It never becomes a verdict.
  • “Unknown” is its own answer. Twelve of the first twenty “maybes” really meant “couldn't find out”, so I split them out.
  • Private stays private. Visitors see the data through a restricted view that never includes private domains or my notes, so a bug on one page can't leak them.
  • The AI chooses, the code counts. For charts, the AI only picks what kind of chart to draw. Every number is calculated by ordinary code, from data the visitor is allowed to see.
  • Cheap to run. Free checks run before paid ones, lookups are reused, and visitor features use a cheaper AI model with limits.

What went wrong

For seven weeks, the accounts that pay for web searches and the AI ran out of credit. The radar kept running, and its daily report correctly said it couldn't check anything, but nobody was reading the report. Reporting a failure honestly only helps if someone is watching. Because every filing had been saved, the missed weeks could be checked afterwards instead of being lost.
