# Portfolio

Nitya Sree Cheera: https://nityasreecheera.github.io/portfolio/

Static pages, no build step. GitHub Pages serves them from `main`.

- `index.html` is the home page: introduction, about, and a card for each project.
- Each project has its own folder with an `index.html`, for example `deal-radar/`.
- `style.css` is shared by every page; screenshots live in `images/`.

To add a project, copy one of the project folders, rewrite it, and add a card to `index.html`.
